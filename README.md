# SQL Advent Calendar 2025

This repository contains my solutions to Interview Master's 24-day SQL Advent Calendar challenge.

## About the Challenge

The SQL Advent Calendar is a festive coding challenge featuring 24 days of Christmas-themed SQL problems, hosted by Interview Master.

Each day, I solved a SQL problem ranging from "Easy" to "Difficult". This allowed me to practice my skills on hands-on exercises that covered concepts from basic queries to complex joins, CTEs and window functions. With this challenge, my goal was to gain confidence in my abilities and move on from Datacamp courses to writing real queries. In the end, I was able to solve challenges marked as "Difficult" with way more ease than at the start, and understand what clauses or functions I could use in which situation, thus forming my own logic. 

Learn more at [interviewmaster.ai/advent](https://www.interviewmaster.ai/advent)
